An interactive Martian exploration and navigation platform designed to help future astronauts explore Mars, identify scientifically significant locations, understand terrain conditions, and plan safer surface exploration routes.



## About the Project

Martian Map is our solution to the NASA Space Apps Challenge 2026.

Our goal is to make Mars exploration more accessible through an interactive map that brings together NASA planetary data, scientific locations, terrain information, and exploration tools.

The platform focuses on helping users understand the Martian landscape and visualize potential exploration routes while considering terrain conditions and possible hazards.

## How to Use Martian Map

Follow these steps to explore the platform:

1. **Open the Live Website:** Visit [https://martianmap.hax.com.bd](https://martianmap.hax.com.bd).
2. **Explore the Martian Map:** Navigate the interactive map and explore the Jezero Crater region.
3. **Explore Map Layers:** Turn available data layers on or off to understand different Martian surface features.
4. **Discover Scientific Locations:** Explore scientifically significant locations and available research information.
5. **Analyze Terrain:** Use elevation, slope, and hazard information to understand the surface conditions.
6. **Plan an Exploration Route:** Select a starting point and destination to visualize a potential route across the Martian surface.
7. **Review the Route:** Examine the proposed path and its terrain-related considerations before exploration.
8. **Explore Data Sources:** Visit the `/sources` page to review NASA imagery, data sources, and credits.

*Note: Available features and data depend on the currently integrated datasets.*

## NASA Data & Resources

The project uses real NASA imagery and planetary science resources to support Martian exploration.

- **NASA Images:** 17 real NASA images stored as JPG assets.
- **Terrain Data:** Elevation and terrain-related information.
- **Scientific Locations:** Locations relevant to Martian scientific exploration.
- **Hazard Information:** Terrain-related information for route assessment.
- **Data Provenance:** NASA sources and image credits are documented on the Data Sources page.

For detailed references and credits, visit the [Data Sources](https://martianmap.hax.com.bd/sources) page.

## Run Locally

Want to run the project on your computer?

**Prerequisites:**
- Node.js
- npm
- Git

**Installation**

```bash
# Clone the repository
git clone <your-repository-url>

# Navigate to the project directory
cd <repository-name>

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be available at the local URL displayed in your terminal.
